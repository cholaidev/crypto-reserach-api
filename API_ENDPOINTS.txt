Crypto Research API Endpoints
============================

Base URL:
http://localhost:3001/api

1) Health check
Method: GET
Endpoint: /api/health
Description: Checks whether the backend is running.
Example: http://localhost:3001/api/health

Response:
{
  "success": true,
  "data": {
    "status": "ok",
    "message": "Crypto Research API is healthy"
  }
}

2) Get market list
Method: GET
Endpoint: /api/coins
Description: Returns a list of crypto coins with market info.
Query params:
- currency (default: usd)
- page (default: 1)
- perPage (default: 50)
- order (default: market_cap_desc)
Example: http://localhost:3001/api/coins?currency=usd&page=1&perPage=10

Response:
{
  "success": true,
  "data": [
    {
      "id": "bitcoin",
      "name": "Bitcoin",
      "symbol": "btc",
      "image": "https://assets.coingecko.com/coins/images/1/large/bitcoin.png",
      "current_price": 67200,
      "price_change_percentage_24h": 2.3,
      "market_cap": 1320000000000,
      "total_volume": 58000000000,
      "circulating_supply": 19600000,
      "market_cap_rank": 1
    }
  ]
}

3) Get coin details
Method: GET
Endpoint: /api/coins/:id
Description: Returns details for one specific coin.
Example: http://localhost:3001/api/coins/bitcoin

Response:
{
  "success": true,
  "data": {
    "id": "bitcoin",
    "name": "Bitcoin",
    "symbol": "btc",
    "description": "Bitcoin is a decentralized digital currency without a central bank or single administrator.",
    "current_price": 67200,
    "market_cap": 1320000000000,
    "total_volume": 58000000000,
    "high_24h": 68250,
    "low_24h": 65500
  }
}

4) Get chart data
Method: GET
Endpoint: /api/coins/:id/chart
Description: Returns price, volume, and market cap chart data for a coin.
Query params:
- days (supported: 1, 7, 30, 90, 365)
- currency (default: usd)
Example: http://localhost:3001/api/coins/bitcoin/chart?days=7&currency=usd

Response:
{
  "success": true,
  "data": {
    "prices": [[1725000000000, 66000], [1725003600000, 66500]],
    "market_caps": [[1725000000000, 1300000000000]],
    "total_volumes": [[1725000000000, 55000000000]]
  }
}

5) Search coins
Method: GET
Endpoint: /api/coins/search
Description: Searches for coins by name or symbol.
Query params:
- q
- or query
Example: http://localhost:3001/api/coins/search?q=bitcoin
Example: http://localhost:3001/api/coins/search?query=bitcoin

Response:
{
  "success": true,
  "data": [
    {
      "id": "bitcoin",
      "name": "Bitcoin",
      "symbol": "btc",
      "image": "https://assets.coingecko.com/coins/images/1/thumb/bitcoin.png",
      "market_cap_rank": 1
    }
  ]
}

6) Global market stats
Method: GET
Endpoint: /api/market/global
Description: Returns global market summary statistics.
Example: http://localhost:3001/api/market/global

Response:
{
  "success": true,
  "data": {
    "total_market_cap": 2500000000000,
    "total_volume": 98000000000,
    "active_cryptocurrencies": 4200,
    "markets": 512,
    "market_cap_percentage": {
      "btc": 53.2,
      "eth": 18.7
    }
  }
}

Error format:
{
  "success": false,
  "message": "Something went wrong",
  "code": "ERROR_CODE"
}

Common error codes:
- INVALID_SEARCH_QUERY
- INVALID_CHART_DAYS
- COINGECKO_API_ERROR
- MISSING_API_KEY
- AUTH_FAILED
- RATE_LIMITED

Mock mode:
Set USE_MOCK_DATA=true in the environment to use built-in demo data without a CoinGecko key.
